Privacy First

你的云盘凭证，永远不离开你的设备

挂载所需的登录凭证只保存在你本机、并经设备绑定加密。我们的服务器从不存储、不接触你的网盘账号或访问令牌（token）——没有凭证上云，自然没有被泄露或被盗用的风险。

🛡️

FusionCloud 的做法

凭证仅存本地、设备绑定加密 · 服务器零接触你的 token · 卸载即清除 · 你始终掌握自己的账号。

⚠️

把 token 托管到对方网站的方案

需要你把云盘 token 持久化上传到对方服务器 · 凭证集中存储 · 一旦服务器被攻破，账号面临批量泄露风险。

安全不是附加项，而是 FusionCloud 的默认设计。

FAQ

常见问题

FusionCloud 支持哪些网盘？

目前支持天翼云盘、百度网盘、夸克网盘、阿里云盘，后续将持续接入更多网盘服务。

支持对象存储吗？

支持。FusionCloud 可挂载天翼云 ZOS / OOS、阿里云 OSS、AWS S3 及各类 S3 兼容对象存储（如 MinIO、Cloudflare R2），并陆续支持腾讯云 COS、华为云 OBS、WebDAV / SFTP 等，把存储桶当作本地磁盘直接读写。

挂载后会把所有文件下载到电脑上吗？

不会。FusionCloud 采用按需下载，文件仅在你打开时才从云端获取，并使用本地缓存加速，不会占满你的硬盘空间。

支持哪些操作系统？

FusionCloud 支持 Windows、macOS、Linux 桌面端，以及 NAS（通过 Docker 部署）。同一账号体系可在多平台使用。移动端在规划中。

我的网盘账号和密码安全吗？

账号登录凭证经过设备绑定加密后存储在你本机，仅本设备可解密，不会明文上传或共享。

免费版和专业版的区别？

免费版可挂载 1 个网盘并使用全部核心功能；专业版支持同时挂载多个网盘 / 多个账号、跨盘操作及优先支持。

专业版如何付费？可以退款吗？

专业版付费方案即将开放，上线后将支持支付宝在线支付、付费后即时生效。退款政策详见 退款与售后说明。
