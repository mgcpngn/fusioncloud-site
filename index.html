NAS Docker

飞牛 / NAS 里找不到挂载盘？看这里

Docker 版挂载成功后，不会在 NAS 里自动多一个盘符。云盘先挂在容器内 /media/MyCloud/<账号目录>，需要把这个目录绑定到 NAS 上一个真实文件夹，NAS 文件管理器才能看到。

1. 在 NAS 建两个文件夹

fusioncloud-data 保存配置和缓存；fusioncloud-media 用来显示云盘文件。

2. 让 media 目录支持挂载传播 
sudo mount --bind /mnt/fusioncloud-media /mnt/fusioncloud-media
sudo mount --make-rshared /mnt/fusioncloud-media
3. 运行容器时映射真正的挂载出口 
docker run -d --name fusioncloud \
  --restart unless-stopped \
  -p 5174:5174 \
  --cap-add SYS_ADMIN \
  --device /dev/fuse:/dev/fuse \
  --security-opt apparmor:unconfined \
  -v /mnt/fusioncloud-data:/data \
  --mount type=bind,src=/mnt/fusioncloud-media,dst=/media/MyCloud,bind-propagation=rshared \
  fusioncloud:0.4.18
挂载后在哪里操作？ 浏览器里挂载成功后，到 NAS 文件管理器打开 /mnt/fusioncloud-media/<账号目录>。不要去 /data 找，/data 只是 FusionCloud 的数据目录。
Synology DSM

群晖 NAS 专用配置：先建共享文件夹，再挂载

群晖和飞牛不一样：SSH 里 mkdir /volume1/fusioncloud-media 只是在 Linux 下建目录，DSM 控制面板和 File Station 不会自动把它当共享文件夹。必须先在 DSM 里手工创建共享文件夹并给用户读写权限，再用命令行打开挂载传播。

1. DSM 创建共享文件夹

控制面板 → 共享文件夹 → 新增，名称填 fusioncloud-media，位置选 volume1。创建后给当前 DSM 用户和 administrators 组授予读写权限，并确认 File Station 能看到空的 fusioncloud-media。

2. SSH 准备数据目录和传播 
sudo -i
mkdir -p /volume1/docker/fusioncloud/data
chmod 0777 /volume1/docker/fusioncloud/data /volume1/fusioncloud-media
mount --bind /volume1/fusioncloud-media /volume1/fusioncloud-media
mount --make-rshared /volume1/fusioncloud-media
3. 用共享文件夹启动容器 
docker run -d --name fusioncloud \
  --restart unless-stopped \
  -p 5174:5174 \
  --cap-add SYS_ADMIN \
  --device /dev/fuse:/dev/fuse \
  --security-opt apparmor:unconfined \
  -v /volume1/docker/fusioncloud/data:/data \
  --mount type=bind,src=/volume1/fusioncloud-media,dst=/media/MyCloud,bind-propagation=rshared \
  fusioncloud:0.4.18
FusionCloud 页面怎么填？ 挂载引擎选 rclone，挂载点填容器内路径 /media/MyCloud/<账号>，挂载目录选 /。挂载成功后，群晖 File Station 打开 fusioncloud-media/<账号> 查看文件。Video Station / Moments / Synology Photos 还依赖 DSM 媒体索引，不能等同于 File Station 可见；媒体库场景更建议用 Jellyfin / Plex / Emby 这类 Docker 服务读取同一个共享文件夹。

FAQ

常见问题

FusionCloud 支持哪些网盘？

目前支持天翼云盘、百度网盘、夸克网盘，后续将持续接入更多网盘服务。

支持对象存储吗？

支持。FusionCloud 可挂载天翼云 ZOS / OOS、阿里云 OSS、AWS S3 及各类 S3 兼容对象存储（如 MinIO、Cloudflare R2），并陆续支持腾讯云 COS、华为云 OBS、WebDAV / SFTP 等，把存储桶当作本地磁盘直接读写。

挂载后会把所有文件下载到电脑上吗？

不会。FusionCloud 采用按需下载，文件仅在你打开时才从云端获取，并使用本地缓存加速，不会占满你的硬盘空间。

支持哪些操作系统？

正式支持 Windows 10/11 与 Windows Server（2016 / 2019 / 2022 及更早的老版本均可，天翼云电脑等云主机环境同样适用）、Linux 桌面端（Debian/Ubuntu/UOS 等，含 ARM64），以及 NAS / 服务器（通过 Docker 部署）。macOS 目前提供 Apple Silicon 实验性预览版（未签名、需 macFUSE，挂载尚在打磨中），可在下载区体验。移动端在规划中。

群晖 / 飞牛 / NAS 里看不到 Docker 挂载盘怎么办？

Docker 版会按 NAS 容器环境默认选择 rclone，并在挂载前提示 /media/MyCloud 是否可写、是否只是容器内部目录、是否缺少共享传播。飞牛通常映射一个普通宿主目录即可；群晖必须先在 DSM「控制面板 → 共享文件夹」里创建 fusioncloud-media，给当前用户读写权限，并确认 File Station 能看到空共享文件夹，然后再执行 mount --bind / mount --make-rshared 和 Docker 启动命令。/data 只是配置、日志和缓存目录，不会显示云盘文件。

我的网盘账号和密码安全吗？

账号登录凭证经过设备绑定加密后存储在你本机，仅本设备可解密，不会明文上传或共享。
